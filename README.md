# Kora

Making economic activity visible.

## Problem

Small entrepreneurs generate real economic activity but often lack structured financial data that can help institutions understand their business.

## Solution

Kora is an Economic Passport that transforms business activity data into a structured, understandable and shareable economic profile.

## MVP

- Activity data import
- AI-powered activity analysis
- Economic Passport
- Entrepreneur dashboard
- Financeur view
